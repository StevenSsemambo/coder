# SQL error messages in Kiswahili: for a native speaker to review

The SQL track shows a friendly explanation when a learner's query fails, in English and in Kiswahili. The Kiswahili text below was written by Claude and has **not yet been checked by a native speaker**. Please read each row and correct anything that sounds unnatural, wrong, or too formal for a diploma student on a phone. Technical words used: *jedwali* (table), *safu* (column), *mstari* (row), *hifadhidata* (database), *ufunguo wa kigeni* (foreign key), *muamala* (transaction), *mwonekano* (view), *kitendakazi* (function). If a better everyday word exists for any of them, say so and we will use it everywhere. **The words I am least sure of:** *faharasa* (index), *kichochezi* (trigger) and *mwonekano* (view).

To change a message, edit the `sw` part of the rule with the same id in `src/lib/errors.js`.

| Rule id | The mistake | English (title, why, fix) | Kiswahili (title, why, fix) |
|---|---|---|---|
| `sql-no-table` | `SELECT * FROM pupils;`<br>SQLite says: `no such table: pupils` | **There is no table called "pupils"** SQLite looked for a table named pupils in the practice database and did not find one. The name may be spelled differently, or the table may not exist in this lesson. *Fix:* Check the table name in the lesson: capital letters do not matter in SQL, but every other letter does. To see every table, run: SELECT name FROM sqlite_master WHERE type = 'table'; | **Hakuna jedwali linaloitwa "pupils"** SQLite ilitafuta jedwali liitwalo pupils kwenye hifadhidata ya mazoezi na haikuliona. Jina linaweza kuwa limeandikwa tofauti, au jedwali hilo halipo kwenye somo hili. *Fix:* Angalia jina la jedwali kwenye somo. Kuona majedwali yote, endesha: SELECT name FROM sqlite_master WHERE type = 'table'; |
| `sql-no-column` | `SELECT colour FROM t;`<br>SQLite says: `no such column: colour` | **There is no column called "colour"** The table has no column with that name. Often the name is misspelled, or text was written without quotes (SQL reads colour as a column name, not as text). *Fix:* Look at the column names with SELECT * FROM tablename LIMIT 1; If you meant text, put it in single quotes, like 'Kampala'. | **Hakuna safu inayoitwa "colour"** Jedwali halina safu yenye jina hilo. Mara nyingi jina limekosewa tahajia, au maandishi yameandikwa bila nukuu (SQL inasoma colour kama jina la safu, si maandishi). *Fix:* Angalia majina ya safu kwa SELECT * FROM jina_la_jedwali LIMIT 1; Kama ulimaanisha maandishi, yaweke ndani ya nukuu moja, mfano 'Kampala'. |
| `sql-syntax` | `SELECT name FORM t;`<br>SQLite says: `near "t": syntax error` | **SQL did not understand the part near "t"** Something is wrong at or just before t: a keyword may be misspelled, a comma may be missing or extra, or two parts are in the wrong order (SELECT, then FROM, then WHERE, and so on). *Fix:* Read the line slowly from the left. Check the spelling of every keyword, check the commas between column names (none after the last one), and check that quotes and brackets come in pairs. | **SQL haikuelewa sehemu karibu na "t"** Kuna kosa pale t ilipo au kabla yake: neno kuu linaweza kuwa na tahajia mbaya, koma inaweza kukosekana au kuzidi, au sehemu mbili ziko kwenye mpangilio usio sahihi (SELECT, kisha FROM, kisha WHERE, na kadhalika). *Fix:* Soma mstari polepole kutoka kushoto. Angalia tahajia ya kila neno kuu, koma kati ya majina ya safu (hakuna baada ya ya mwisho), na nukuu na mabano yawe kwa jozi. |
| `sql-incomplete` | `SELECT name FROM t WHERE name = 'Amina;`<br>SQLite says: `unrecognized token: "'Amina;"` | **The SQL stops too early, or a quote is not closed** The statement is not finished. Usually a closing quote ' or a closing bracket ) is missing. *Fix:* Count your quotes and brackets: every opening one needs a closing one. Text goes in single quotes. | **SQL inaishia mapema, au nukuu haijafungwa** Amri haijakamilika. Mara nyingi nukuu ya kufunga ' au mabano ya kufunga ) yamekosekana. *Fix:* Hesabu nukuu na mabano yako: kila ya kufungua inahitaji ya kufunga. Maandishi huwekwa ndani ya nukuu moja. |
| `sql-ambiguous` | `SELECT name FROM t, u;`<br>SQLite says: `ambiguous column name: name` | **"name" could mean more than one column** Two tables in your query both have a column called name, so SQL cannot guess which one you want. *Fix:* Put the table name in front, with a dot: tablename.name | **"name" inaweza kumaanisha safu zaidi ya moja** Majedwali mawili kwenye hoja yako yote yana safu iitwayo name, kwa hiyo SQL haiwezi kubahatisha unataka ipi. *Fix:* Weka jina la jedwali mbele, kwa nukta: jina_la_jedwali.name |
| `sql-unique` | `INSERT INTO t VALUES (1, 'Amina');`<br>SQLite says: `UNIQUE constraint failed: t.id` | **That value already exists** The column t.id must be different in every row (it is a key or is marked UNIQUE), and you tried to add a value that is already there. *Fix:* Use a new value, or change the existing row with UPDATE instead of adding a second one. | **Thamani hiyo tayari ipo** Safu t.id lazima iwe tofauti kwenye kila mstari (ni ufunguo au imewekwa UNIQUE), nawe ulijaribu kuongeza thamani iliyopo tayari. *Fix:* Tumia thamani mpya, au badilisha mstari uliopo kwa UPDATE badala ya kuongeza wa pili. |
| `sql-not-null` | `INSERT INTO t (id) VALUES (9);`<br>SQLite says: `NOT NULL constraint failed: t.name` | **A required value is missing** The column t.name may not be empty (NULL), but the row you tried to add has no value for it. *Fix:* Give that column a value in your INSERT, and check that the columns and the values are in the same order. | **Thamani inayohitajika haipo** Safu t.name haiwezi kuwa tupu (NULL), lakini mstari uliojaribu kuongeza hauna thamani yake. *Fix:* Toa thamani kwa safu hiyo kwenye INSERT yako, na hakikisha safu na thamani ziko kwa mpangilio uleule. |
| `sql-column-count` | `INSERT INTO t VALUES (7, 'Sam', 3);`<br>SQLite says: `table t has 2 columns but 3 values were supplied` | **The number of values does not match the number of columns** Your INSERT gives a different number of values than the number of columns it fills. *Fix:* Count them. If you name the columns, write exactly one value for each, in the same order. | **Idadi ya thamani hailingani na idadi ya safu** INSERT yako inatoa idadi tofauti ya thamani kuliko idadi ya safu inazojaza. *Fix:* Zihesabu. Ukitaja safu, andika thamani moja kwa kila safu, kwa mpangilio uleule. |
| `sql-aggregate-where` | `SELECT name FROM t WHERE COUNT(*) > 1;`<br>SQLite says: `misuse of aggregate function COUNT()` | **COUNT, SUM, AVG, MIN and MAX cannot be used in WHERE** WHERE picks rows one by one, before any totals exist. A total can only be tested after the rows are grouped. *Fix:* Use HAVING (after GROUP BY) to test a total, for example HAVING COUNT(*) > 2. | **COUNT, SUM, AVG, MIN na MAX haviwezi kutumika kwenye WHERE** WHERE huchagua mistari moja moja, kabla ya jumla yoyote kuwepo. Jumla inaweza kupimwa tu baada ya mistari kuwekwa kwenye vikundi. *Fix:* Tumia HAVING (baada ya GROUP BY) kupima jumla, mfano HAVING COUNT(*) > 2. |
| `sql-no-function` | `SELECT NOW();`<br>SQLite says: `no such function: NOW` | **SQLite has no function called NOW** The name NOW is not a function SQLite knows. It may be misspelled, or it may exist in another database system (MySQL or SQL Server) but not in SQLite. *Fix:* Check the spelling. Common SQLite functions: COUNT, SUM, AVG, MIN, MAX, ROUND, LENGTH, UPPER, LOWER, SUBSTR, REPLACE, COALESCE, DATE. | **SQLite haina kitendakazi kiitwacho NOW** Jina NOW si kitendakazi ambacho SQLite inakijua. Linaweza kuwa limekosewa tahajia, au lipo kwenye mfumo mwingine (MySQL au SQL Server) lakini si SQLite. *Fix:* Angalia tahajia. Vitendakazi vya kawaida vya SQLite: COUNT, SUM, AVG, MIN, MAX, ROUND, LENGTH, UPPER, LOWER, SUBSTR, REPLACE, COALESCE, DATE. |
| `sql-table-exists` | `CREATE TABLE t (a INT);`<br>SQLite says: `table t already exists` | **The table "t" already exists** You tried to create a table with a name that is already taken in this database. *Fix:* Choose a different name, or write CREATE TABLE IF NOT EXISTS t ... so SQL skips it when it is already there. | **Jedwali "t" tayari lipo** Ulijaribu kuunda jedwali kwa jina ambalo tayari limetumika kwenye hifadhidata hii. *Fix:* Chagua jina tofauti, au andika CREATE TABLE IF NOT EXISTS t ... ili SQL iruke kama tayari lipo. |
| `sql-check` | `CREATE TABLE k (n INT CHECK (n > 0)); INSERT INTO k VALUES (-1);`<br>SQLite says: `CHECK constraint failed: n > 0` | **The value breaks a rule of the table** This table has a rule (CHECK n > 0) and the value you tried to save does not obey it, so SQLite refused the whole change. *Fix:* Use a value that follows the rule, or change the rule if the rule itself is wrong. | **Thamani inavunja sheria ya jedwali** Jedwali hili lina sheria (CHECK n > 0) na thamani uliyojaribu kuhifadhi haiitii, kwa hiyo SQLite ilikataa mabadiliko yote. *Fix:* Tumia thamani inayofuata sheria, au badilisha sheria kama sheria yenyewe ndiyo yenye kosa. |
| `sql-no-column-named` | `INSERT INTO t (colour) VALUES ('x');`<br>SQLite says: `table t has no column named colour` | **The table t has no column called "colour"** Your INSERT names a column (colour) that t does not have. The name may be misspelled. *Fix:* See the real column names with PRAGMA table_info(t); and use exactly those. | **Jedwali t halina safu inayoitwa "colour"** INSERT yako inataja safu (colour) ambayo t haina. Jina linaweza kuwa limekosewa tahajia. *Fix:* Angalia majina halisi ya safu kwa PRAGMA table_info(t); kisha utumie hayohayo. |
| `sql-add-notnull` | `ALTER TABLE t ADD COLUMN level INTEGER NOT NULL;`<br>SQLite says: `Cannot add a NOT NULL column with default value NULL` | **A new required column needs a starting value** The table already has rows. A new NOT NULL column would be empty in all of them, which breaks its own rule. *Fix:* Give the column a default, for example: ALTER TABLE t ADD COLUMN level INTEGER NOT NULL DEFAULT 1; | **Safu mpya inayohitajika inahitaji thamani ya kuanzia** Jedwali tayari lina mistari. Safu mpya ya NOT NULL ingekuwa tupu kwenye yote, jambo linalovunja sheria yake yenyewe. *Fix:* Ipe safu thamani ya msingi, kwa mfano: ALTER TABLE t ADD COLUMN level INTEGER NOT NULL DEFAULT 1; |
| `sql-foreign-key` | `PRAGMA foreign_keys = ON; CREATE TABLE ch (p INTEGER REFERENCES t(id)); INSERT INTO ch VALUES (99);`<br>SQLite says: `FOREIGN KEY constraint failed` | **That row points at something that does not exist, or is still needed** A foreign key links this row to a row in another table. Either the row you are adding points at a parent that is not there (for example a customer number nobody has), or you are deleting a parent that other rows still point at. *Fix:* Check that the number you point at exists in the other table. To delete a parent, first delete or change the rows that point at it. | **Mstari huo unaelekeza kwenye kitu ambacho hakipo, au bado kinahitajika** Ufunguo wa kigeni unaunganisha mstari huu na mstari kwenye jedwali lingine. Ama mstari unaoongeza unaelekeza kwa mzazi asiyekuwepo (kwa mfano namba ya mteja ambayo haipo), au unafuta mzazi ambaye mistari mingine bado inamtegemea. *Fix:* Hakikisha namba unayoelekeza ipo kwenye jedwali lingine. Ili kufuta mzazi, kwanza futa au badilisha mistari inayomwelekea. |
| `sql-subquery-columns` | `SELECT * FROM t WHERE id IN (SELECT id, name FROM t);`<br>SQLite says: `sub-select returns 2 columns - expected 1` | **The inner query must return exactly one column here** The query in brackets returns 2 columns, but IN (...) or a comparison can only use one column of values. *Fix:* Select just the one column you need in the brackets, for example IN (SELECT customer_id FROM orders). | **Hoja ya ndani lazima irudishe safu moja tu hapa** Hoja ndani ya mabano inarudisha safu 2, lakini IN (...) au ulinganisho unaweza kutumia safu moja ya thamani tu. *Fix:* Chagua safu moja unayohitaji ndani ya mabano, kwa mfano IN (SELECT customer_id FROM orders). |
| `sql-view-modify` | `CREATE VIEW vv AS SELECT id FROM t; INSERT INTO vv VALUES (5);`<br>SQLite says: `cannot modify vv because it is a view` | **vv is a view, so you cannot change rows in it** A view is a saved question, not a table that holds rows. There is nothing in vv to add to, change or delete. *Fix:* Run your INSERT, UPDATE or DELETE on the real table that the view reads from. | **vv ni mwonekano (view), kwa hiyo huwezi kubadilisha mistari ndani yake** Mwonekano ni swali lililohifadhiwa, si jedwali lenye mistari. Hakuna kitu ndani ya vv cha kuongeza, kubadilisha au kufuta. *Fix:* Endesha INSERT, UPDATE au DELETE yako kwenye jedwali halisi ambalo mwonekano unalisoma. |
| `sql-transaction` | `COMMIT;`<br>SQLite says: `cannot commit - no transaction is active` | **There is nothing to commit: no transaction was started** COMMIT ends a transaction, but BEGIN was never run (or the transaction already ended). *Fix:* Start with BEGIN; do the changes; then finish with COMMIT; (keep them) or ROLLBACK; (undo them). | **Hakuna cha kuthibitisha: hakuna muamala ulioanzishwa** COMMIT humaliza muamala, lakini BEGIN haikuendeshwa (au muamala ulishaisha). *Fix:* Anza na BEGIN; fanya mabadiliko; kisha malizia na COMMIT; (yabaki) au ROLLBACK; (yaondolewe). |
| `sql-window-misuse` | `SELECT id FROM t WHERE ROW_NUMBER() OVER (ORDER BY id) = 1;`<br>SQLite says: `misuse of window function ROW_NUMBER()` | **A window function cannot be used in WHERE** WHERE runs before window functions such as ROW_NUMBER, RANK or SUM(...) OVER are worked out, so it cannot see their results. *Fix:* Work the window function out inside a WITH (or a subquery), then filter on its result in the outer query. | **Kitendakazi cha dirisha hakiwezi kutumika kwenye WHERE** WHERE huendeshwa kabla vitendakazi vya dirisha kama ROW_NUMBER, RANK au SUM(...) OVER havijahesabiwa, kwa hiyo haviwezi kuona matokeo yake. *Fix:* Hesabu kitendakazi cha dirisha ndani ya WITH (au hoja ya ndani), kisha chuja kwa matokeo yake kwenye hoja ya nje. |
