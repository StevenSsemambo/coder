C++ phone test

Checks whether a real C++ compiler (LLVM/Clang built for WebAssembly) can run inside a phone browser, for the SayMaCoder app. Nothing here is the app itself, and nothing is sent anywhere.

Before you start
  • Use Wi-Fi. The first run downloads about 105 MB (about 27 MB if your network compresses it).
  • Open this page in a private / incognito tab in the phone’s normal browser (Chrome or Safari), not inside the installed app.
  • Close other apps. Keep the screen on and stay on this page until it finishes. It can take a few minutes.
  • If the page crashes or the browser closes, open it again. That is an important result too, and the page will tell you which step it stopped at.
